# Primer: finding exoplanets in TESS data, from the what to the how

A series of short articles for readers with no astronomy background. The first one explains
what we are trying to find and what can fool us; each of the following ones explains one
stage of this repository's pipeline, at a level just below the code and its walkthrough
notebooks.
